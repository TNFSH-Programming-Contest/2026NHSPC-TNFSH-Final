\section{C. 一棵簡單的樹}

\begin{frame}{\btitle{題目敘述}}
    $n$ 點樹，$1$ 為根，上面有一些石頭。

    輪流行動，每次選擇一個非空且不是根的節點，把石頭往上丟。

    不能動的人是給。
\end{frame}

\begin{frame}{\btitle{子任務}}
    \begin{enumerate}
        \item{$1 \le N \le 2$}
        \item{除了根節點外，每個節點的親代皆為節點 $1$}
        \item{對所有 $1 \le i < N$，第 $i$ 條邊連接節點 $i$ 與 $i+1$}
        \item{對所有 $1 \le i \le N$，$0 \le A_i \le 1$}
        \item{無額外限制}
    \end{enumerate}
\end{frame}

\begin{frame}{\btitle{無額外限制}}
    首先觀察到可以把石頭分成兩種情況。

    \begin{itemize}
        \item {偶數深度的石頭}
        \item {奇數深度的石頭}
    \end{itemize}

    發現移動偶數深度的時候，對手也可以再把它動回去偶數深度

    所以偶數深度的石頭視為消失在賽局中。

    那麼也就是在奇數深度的石頭上做一般的 nim game，就解出來了。
\end{frame}
