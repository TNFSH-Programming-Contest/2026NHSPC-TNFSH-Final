# 石頭遊戲

給定一棵以節點 $1$ 為根、包含 $N$ 個節點的樹。節點 $i$ 上一開始有 $A_i$ 顆石頭。

Alice 與 Bob 輪流行動，由 Alice 先行。每次行動可以選擇一個不是根、且仍有石頭的節點，從中拿走任意正整數顆石頭，並將這些石頭全部移到該節點的親代。無法行動的人輸掉遊戲。

## 輸入

第一行包含一個整數 $N$，代表樹的節點數。

第二行包含 $N$ 個整數 $A_1,A_2,\ldots,A_N$，其中 $A_i$ 代表節點 $i$ 一開始的石頭數量。

接下來 $N-1$ 行，每行包含兩個整數 $u_i,v_i$，代表節點 $u_i$ 與節點 $v_i$ 之間有一條無向邊。將樹以節點 $1$ 為根後，每個非根節點的親代即為它通往節點 $1$ 的路徑上的下一個節點。

## 輸出

若 Alice 有必勝策略，輸出 `Alice`；否則輸出 `Bob`。

## 輸入限制

- $1 \le N \le 2 \times 10^5$
- $0 \le A_i \le 10^9$
- $1 \le u_i,v_i \le N$
- 輸入的 $N-1$ 條邊構成一棵樹。
